### Project Resume Summary

**Project Name:** Mudda
**Description:** A communication and issue-tracking platform designed to facilitate seamless interaction between the government and citizens. The system allows users to report municipal or civic issues and track their resolution status across different administrative levels and geographical areas. 

**Key Highlights:**
* Developed a scalable RESTful backend architecture using **Java** and **Spring Boot 3**.
* Implemented complex geographical queries and location-based issue tracking using **PostgreSQL**, **PostGIS**, and **Hibernate Spatial**.
* Integrated asynchronous message queuing for robust processing using **AWS SQS**.
* Secured the platform using **Spring Security** combined with **JWT** token-based authentication and rate limiting via **Bucket4j**.
* Orchestrated local development and testing environments using **Docker Compose** with services like **LocalStack** (AWS simulation), **MailHog** (email testing), and a full observability stack (**Grafana**, **InfluxDB**, **Telegraf**).
* Integrated file validation using **Apache Tika** and utilized **AWS S3** for media storage.
